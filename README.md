# 🎮 Number Guessing Game

A simple interactive console-based Python game where the user attempts to guess a randomly generated secret number between 1 and 100.

## 🚀 Features

- **Random Number Generation**: Pick a new secret number every time you play using Python's `random` module.
- **Dynamic Hints**: Provides instant feedback after each guess ("Too high!" or "Too low!").
- **Attempt Tracking**: Counts and displays the total number of attempts taken to guess the correct number.
- **Input Validation**: Gracefully handles invalid non-integer inputs without crashing the game.

## 📋 Prerequisites

- **Python 3.x** installed on your system.

## 🛠️ How to Run

1. Clone or download this repository to your local machine.
2. Open your terminal or command prompt.
3. Navigate to the directory containing the code file (e.g., `game.py`).
4. Run the script using Python:
